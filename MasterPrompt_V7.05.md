#### 1.1 Cognitive Load Theory (Sweller) & Split-Attention Elimination

- **Docked Reference Drawer (`#scenarioDrawer`):** Never force a student to flip back to page 1 or memorize numbers. The complete scenario prompt, pricing tables, allowance rules, and GUI control naming matrices must be accessible via a persistent slide-out drawer or sticky reference panel toggleable from the palette bar.

- **Scaffolding Without Answer Giveaways:** Provide realistic visual context (control naming tables, event signatures, read-only UI code skeletons) without leaking algorithmic logic, variable typing, or formula solutions in the question stems.

#### 1.2 Continuous Single-Sheet Examination Invariant

- **Zero Carousel Steppers for Official Papers:** Official examination papers (`exam_2021_nov`, `exam_2022_dec`, `exam_2023_dec`, `exam_2024_dec`, `exam_2024_pec`) must **NEVER** render as single-question paginated steppers ("Q 1 of 16" with "Next" buttons).

- **Single Vertical Document:** All questions (1 through N) must render stacked vertically on a continuous, scrollable examination paper matching an authentic printed NWU Test 1 paper.

- **Sticky Quick-Jump Docked Matrix:** Positioned immediately below the header with real-time `IntersectionObserver` scroll-spy:

  - Slate: Unanswered (`.unanswered`)

  - Neon Blue: Answered (`.answered`)

  - Glowing Amber: Flagged for Review (`.flagged`)

  - Glowing Cyan Border: Active Viewport Card (`.current-card`)

- **Action Buttons:** Persistent "⏭️ Next Unanswered" circular navigation and a single "📋 Submit Complete Exam Paper" at the document foot.

#### 1.3 Fitts’s Law, Hick’s Law & Visual Hierarchy

- **Target Size & Hit Areas:** Radio options must have a minimum target height of `48px` with full card-width clickability (`padding: 14px 18px`), rounded corners (`8px`), and high-contrast hover/active states.

- **Dark IDE Aesthetic (VS Code Charcoal):**

  - Background Base: `#121418`

  - Card & Surface: `#1a1e24`

  - Borders & Outlines: `#2d333b`

  - Neon Azure: `#007acc` | Neon Teal: `#00bcd4` | Emerald: `#4caf50` | Amber: `#ffb74d` | Coral: `#f44336`

- **Typography:** Google Font `Inter` for UI readability, `JetBrains Mono` / `Fira Code` for syntax blocks. Line height strictly `1.55` to eliminate visual crowding.

#### 1.4 Shneiderman’s 8 Golden Rules of Interface Design (Study Unit 7 Direct Alignment)

1. **Consistency:** Identical typography, button hierarchy, and feedback badges across all Study Units.

2. **Universal Usability:** High contrast ratio (WCAG AAA compliant: `> 7:1`), readable on 320px mobile screens up to 4K displays.

3. **Informative Feedback:** Instant visual state changes upon radio selection, auto-save state indicators, and compiler error diagnostics.

4. **Design Dialogs to Yield Closure:** Comprehensive post-submission review modal with total score, percentage, distinction badge, and detailed question-by-question rationales.

5. **Prevent Errors:** Defensive type validation, disable empty submission without explicit confirmation, and sanitize inputs.

6. **Permit Easy Reversal of Actions:** Instant unchecking/changing of radio buttons, toggleable review flags, and safe code editor resets.

7. **Support Internal Locus of Control:** Students freely navigate any question in any order; timer remains visible; scenario drawer opens without obscuring question context on desktop.

8. **Reduce Short-Term Memory Load:** Retain answers in `localStorage` in real time; preserve state across unintentional page refreshes.
